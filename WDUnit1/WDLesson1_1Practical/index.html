Web Technologies

HTML

HTML stands for Hypertext Markup Language.
It is the standard code used to structure and display content on a web page.
It tells your browser where to put headings, text paragraphs, images, videos, and clickable links.

CSS

CSS stands for Cascading Style Sheets.
It is a style sheet language used to define the visual presentation, layout, and design of a website.
CSS acts as the paint, decor, and styling that makes it look polished and visually appealing.

JavaScript

Javascript is a lightweight, interpreted programming language primarily known as the scripting language for web pages.
It is one of the core technologies of the World Wide Web.
It enables developers to build interactive, dynamic web applications by updating content in real time.
